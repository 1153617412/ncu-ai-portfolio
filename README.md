## 四、快速开始

```bash
# 1) 克隆本仓库到你自己的电脑
git clone <本仓库的 HTTPS 地址>

# 2) 进入目录
cd <仓库目录名>

# 3) 创建并激活虚拟环境（推荐，避免污染系统 Python）
python -m venv .venv
.venv\Scripts\activate          # Windows PowerShell
# source .venv/bin/activate     # macOS / Linux

# 4) 安装课程常用依赖
pip install numpy pandas matplotlib jupyter requests scikit-learn
```
